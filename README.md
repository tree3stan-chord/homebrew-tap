# Homebrew Tap for tree3stan-chord

Homebrew formulae for tree3stan-chord audio and music tools.

## Installation

```bash
brew tap tree3stan-chord/tap
```

## Available Formulas

| Formula | Description | Install |
|---------|-------------|---------|
| **arco** | Terminal-based virtual instrument playground with real-time synthesis | `brew install arco` |

## Quick Install Examples

```bash
# Install the tap first
brew tap tree3stan-chord/tap

# Then install any formula
brew install arco
```
